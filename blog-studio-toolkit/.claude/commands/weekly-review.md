# Review Hebdomadaire

Effectue une review de progression hebdomadaire du projet Blog Studio.

## Instructions

1. **Lis AUDIT_TRACKER.md** — calcule la progression depuis la derniere review
2. **Scan le code** — verifie les changements recents (git log --since="1 week ago")
3. **Recalcule les scores** par domaine en re-analysant le code reel
4. **Identifie les regressions** — nouveau code qui introduit des problemes
5. **Mets a jour AUDIT_TRACKER.md** avec:
   - Taches completees marquees DONE
   - Nouveaux scores par domaine
   - Nouvelles issues decouvertes
   - Progression globale en %
6. **Propose les 5 priorites** pour la semaine suivante
7. **Resume en 5 lignes** ce qui a ete fait, ce qui reste, les blocages

## Output
Mets a jour AUDIT_TRACKER.md et affiche le resume a l'utilisateur.
